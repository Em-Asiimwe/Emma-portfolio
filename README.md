# Emma Asiimwe — Portfolio

A responsive developer portfolio built with semantic HTML, CSS, and vanilla JavaScript.

## Customize it

1. Update the name, bio, email, social links, and project content in `index.html`.
2. Add your PDF resume as `assets/documents/Emma-Asiimwe-Resume.pdf` for the download button.
3. Replace the visual project placeholders with screenshots or images in `assets/images`.
4. Adjust colors, typography, and spacing in `assets/css/style.css`.
5. Open `index.html` in a browser to preview the site.

No build tools or dependencies are required.
